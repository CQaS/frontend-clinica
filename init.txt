Instalaciones basicas Globales.

npm install -g @angular/cli
Verificar version:
ng version

Crear nuevo proyecto de Angular:
ng new frontend-clinica

cree una interfaz de Usuarios:
ng g i modelos/usuario

Crear el Servicio de Usuarios:
ng g s servicios/usuarios

levantar el servidor de Angular:
ng serve -o

En el Navegador deberia verse el json que responde el backend-clinica:
http://localhost:4200/


nginx:
Descargar nginx.org/en/download.html
Descomprimir en C:/nginx
en la carpeta del proyecto frontend-clinica/ ejecutar: ng build

en C:\nginx\conf\nginx.conf editar el bloque server, en root colocar la ruta que nos retorna ng build, ej: "c:\app\proyecto\dist\frontend-clinica\browser"

En la consola en C:/nginx ejecutar: start nginx

En http://localhost se vera la app
